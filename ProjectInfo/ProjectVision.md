1. 这是一个面向游戏行业视频内容的 Hybrid Feed 产品，用 Web 和 iOS 两端把短片段、AI 摘要预览和源站续看整合到同一条信息消费链路里。它的核心不是托管第三方视频，而是更快地帮用户判断“这条内容值不值得继续看”。

2. 要解决的问题是：高价值的游戏行业内容大量散落在 YouTube 等平台，原视频通常很长，用户很难低成本筛选、理解并进入最有用的部分。最早思路依赖站内嵌入播放，但真机验证已经证明这条路不稳定，因为可嵌入性受源视频设置和平台政策控制，地区访问条件也不一致。这个项目因此转向“能播就站内播，不能播就用摘要资产和跳源站承接”的混合模式。

3. 当前已经做到单仓 Web + iOS 原型并行推进，仓库里有 Next.js 前台与 API、SwiftUI iOS 工程、以及对应测试目录。内容模型已经从单一 YouTube 扩展到 YouTube/B 站，并补上了预览模式、摘要资产、区域可用性和 Region Mode 这套协议，Web 与 iOS 都开始按同一套数据语义渲染。还没完成的是把原型能力变成稳定生产链路，尤其是摘要资产生成质量、白名单内容运营、B 站来源管理、真机长期回归和更完整的后台工具。

4. 明确不做的是：不绕过 YouTube 的嵌入限制，不把“任意优质第三方视频都能站内稳定播放”当成产品基座。不做开放式、无边界的大陆视频抓取，第一阶段只适合官方、品牌、自有或白名单来源。不做账号体系、跨设备同步收藏，也不把这期目标定义成公开发布版的全量产品。

5. 主要风险在第三方平台约束本身，这不是前端或播放器微调能彻底解决的问题，YouTube 的嵌入限制和各地区可达性会持续影响体验。另一个风险是摘要资产链路目前更接近内部原型，真正上线后会面临生成质量、转写质量、人工维护成本和版权边界的长期压力。大陆与海外内容池分化也会带来运营复杂度，如果白名单和来源治理跟不上，Feed 质量会直接受影响。
